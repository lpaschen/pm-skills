# /jehiah — Architect Gut-Check

Run the `jehiah-brain` skill against whatever's provided: a PRD, a technical
proposal, an architecture/RFC doc, a migration or rollout plan, or a described
approach that hasn't been written up yet.

## Invocation

```
/jehiah [paste PRD or proposal]
/jehiah We're planning to ramp the new decode path from 1% to 100% over two days — thoughts?
/jehiah [paste architecture doc or link to it]
/jehiah                    # asks what to pressure-test
```

If nothing is provided, ask what to review before proceeding — don't guess at a
proposal that wasn't shared.
