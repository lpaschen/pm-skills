# Product Health Analysis Skill - Complete Content

## Skill Overview
This skill interprets product metrics against organizational goals to identify actionable signals. It integrates with Google Analytics and Mixpanel.

## Core Framework
The analysis examines four metric categories:
- **Acquisition**: new user volume, source quality, customer acquisition cost trends
- **Activation**: speed to initial value, onboarding completion percentage
- **Engagement**: daily/monthly active users, feature adoption rates, session characteristics
- **Retention**: day-1, day-7, day-30 retention metrics, churn patterns, user reactivation

## Analytical Methodology
The process involves:
1. Comparing each metric across time periods and against established benchmarks
2. Identifying metrics deviating 10% or more from targets for deeper examination
3. Investigating potential relationships between metric changes (e.g., onboarding problems potentially impacting retention weeks later)
4. Translating findings into accessible language for diverse audiences
5. Prioritizing the three most critical areas needing immediate focus with diagnostic recommendations

## Deliverable Structure
Reports follow a standardized format including overall health status, comparative metric table, plain-language observations, investigation priorities with hypotheses, and actionable next steps with assigned ownership and timelines.
