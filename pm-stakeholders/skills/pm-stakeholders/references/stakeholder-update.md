# Write a Stakeholder Update

Produce a targeted, audience-appropriate update using BLUF (Bottom Line Up Front). This mode replaces three previously separate tools (an executive-update skill, a general stakeholder-update skill, and an `/update` command) — the templates below are the best of all three, organized by audience instead of by which tool used to produce them.

## Core Principles

- **Lead with the headline, not the context.** Every update should answer: "So what does this mean for the business?"
- **Bottom Line Up Front.** State the conclusion first, then support it — never make the reader hunt for the point.
- **Flag decisions clearly.** Don't bury asks in paragraphs. Name the decision, the options, and your recommendation.
- **Be honest about risks.** Executives hate surprises more than bad news. Make problems visible early and pair them with a proposed mitigation.
- **Use data to tell the story.** Quantified metrics and trend indicators beat activity lists — "Identified #1 barrier to adoption (setup complexity)" beats "ran 12 interviews."

## Process

### Step 1: Establish Context

If not already provided, ask:
- **Who's the audience?** Exec/C-suite, leadership team, cross-functional team, or board/investors
- **What's the goal?** Inform, align, escalate, or celebrate
- **What's the situation?** A recurring status update, a launch, or an escalation
- **What's the cadence?** Daily, weekly, monthly, or quarterly (see Frequency Guidance below)

### Step 2: Pick the Template

Match the audience/situation to one of the four templates below.

### Step 3: Write It

Apply the Core Principles above regardless of which template you use.

## Templates

### Executive Brief (C-suite or VP+)

```markdown
## [Topic] — [Date]

**Bottom Line:** [1 sentence — the most important thing they need to know]

**Status:** 🟢 On Track / 🟡 At Risk / 🔴 Off Track

### By the Numbers
- [Metric]: [value] (vs. target / last period, with trend)
- [Metric]: [value] (vs. target / last period, with trend)

### What's Happening
[2-4 bullets — outcome-focused, only what's materially changed or decided since the last update]

### Decisions Needed
- [Decision] — Options: [A] or [B] — Recommendation: [your view] — Needed by: [date]

### Risks
- [Risk] — [likelihood, impact, mitigation]

### What's Next
[2–3 bullets on next period priorities]
```

Keep the main body to 250 words maximum.

### Team / Cross-Functional Update

```markdown
## [Team/Project] Update — [Date or Sprint]

### Shipped
- [Feature or milestone] — [brief description + link if applicable]

### In Progress
- [Item] — [status, owner, ETA]

### Blocked / At Risk
- [Item] — [blocker, who needs to act, by when]

### Next Up
- [What's starting next sprint or week]

### Metrics
- [Key metric]: [value + trend]
```

### Launch Announcement

```markdown
## [Feature Name] is Live — [Date]

**What it does:** [1-2 sentences on user value]
**Who has it:** [Rollout scope — all users, beta, specific segment]
**Where to learn more:** [Link to help doc, demo, or one-pager]

**Early signal:** [First data point if available — even directional]

**What to watch:** [Metric we're tracking in the next 2 weeks]

**Thank you to:** [Key contributors]
```

### Escalation

```markdown
## Escalation: [Issue] — [Date]

**Issue:** [What is at risk and by how much]
**Impact:** [What happens if unresolved — user impact, revenue, timeline]
**Root Cause:** [Why this is happening]
**Options:**
1. [Option] — [trade-off]
2. [Option] — [trade-off]
**Recommendation:** [What you're asking for]
**Decision needed by:** [Date]
```

Come with options and a recommendation, not just a problem.

---

## Audience Adaptation

Even within a template, calibrate emphasis by audience:

| Audience | Emphasize |
|---|---|
| C-Suite | Business impact, OKR alignment |
| Engineering leadership | Technical context, dependencies |
| Cross-functional teams | Balanced perspective, explicit asks |
| Board / investors | Metrics, positioning, financial implications |

## Frequency Guidance

| Cadence | Format |
|---|---|
| Daily | Ultra-brief — 3 bullets |
| Weekly | Full template, one page |
| Monthly | 2-3 pages, deeper analysis |
| Quarterly | Presentation format for strategic discussion |
