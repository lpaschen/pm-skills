# OKR Builder Skill

This guide helps teams create structured Objectives and Key Results (OKRs) that align work with strategy.

**Core concept:** Objectives answer "where are we going?" (qualitative, inspiring), while Key Results answer "how will we know we've arrived?" (quantitative, measurable).

**Quality standards for Key Results:**
- Scoreable on a 0.0–1.0 scale
- Measures outcomes, not outputs
- Ambitious yet achievable (targeting 70% attainment)
- Within team control
- Includes baseline data

**Common pitfalls to avoid:** Tasks presented as KRs, vanity metrics, binary outcomes, excessive KRs per objective, and missing baseline measurements.

**Recommended structure:** 2–4 objectives per team quarterly, with 3–4 KRs maximum per objective. Each KR should specify measurement method and owner, with weekly check-ins.

**Scoring approach:** 0.7–1.0 indicates success (with 0.7 as ideal), 0.4–0.6 shows partial progress, and 0.0–0.3 indicates missed targets warranting retrospective analysis.

The framework emphasizes that OKRs function as strategic guides, not performance evaluations, so ambitious targets where teams fall short remain acceptable outcomes.
